# TUN Assist preview notice

`0.3.0-preview.3` is an unsigned public desktop pre-release. It is intended for Windows 10/11 x64 with .NET Framework 4.8 and Windows PowerShell 5.1. Live desktop/network-write integration remains unvalidated; this is not a Stable release.

The connected-link EXE, window and sidebar icon is a cosmetic branding update. Network-operation behavior and the seven-language controls are unchanged. The prior user-reported testing applied to `0.3.0-preview.2`, not this exact rebuilt binary; it did not identify individual live Fix/Restore actions.

The app is a focused interface for this unofficial diagnostic project. It does not bundle or manage Clash Verge Rev or Mihomo, and it does not require proxy subscriptions, node addresses or credentials. Viewing status is read-only. A separately confirmed action can change one physical interface's IPv4 packet-forwarding value in ActiveStore.

The originating successful change was performed manually by the user. Later automatic outlet selection and Mips were reported working. That observation is not proof of a Windows kernel cause or a successful GUI integration test. No measured performance improvement, full same-host A/B/A/B or confirmed reboot persistence is available.

Forwarding may be necessary for ICS, Mobile Hotspot, bridging and subnet routing. The app conservatively refuses unsafe or unknown states, but cannot detect every third-party dependency. Snapshots and attempted compensation reduce recovery risk; they cannot guarantee recovery after power loss, forced termination, storage damage or adapter disappearance.

Portable means a single distributed EXE. It can save a local language preference and use machine-scoped protected recovery storage. Closing or deleting the EXE does not restore an earlier network value or remove its snapshots. Do not edit, delete or publicly upload recovery records to bypass a refusal.

The separate Language page offers English, Japanese, Simplified Chinese, Malay, Italian, German and Russian; English is the default, and public repository documentation remains in English. Only a normal non-administrator live session saves the preference, as `%LocalAppData%\TunAssist\language.txt`. Administrator and demo sessions do not save it. Language selection affects display text only, not network settings, identifiers or confirmation words.

The EXE embeds the interface and project scripts, and hosts the installed Windows PowerShell automation runtime in process. It does not bundle the .NET Framework or PowerShell DLLs. Demo, self-test and sample-rendering modes use fixtures and do not inspect or change Windows network settings. They may write the local output files you request.

Status and Activity may reveal local adapter names, identifiers or paths. Redact them before sharing. The tool provides no cloud service or telemetry and does not need an internet connection to inspect local state.

Project code is provided under the [MIT License](../LICENSE), including its warranty terms. Windows and .NET Framework are platform prerequisites. Review [Security](../SECURITY.md) and [Testing](TESTING.md) before any network action.

A public release does not authorize live changes on a particular device. Any network action still requires that device owner's decision and the application's checks and confirmations. Passing automated or read-only checks does not establish live Fix/Restore, privileged snapshot storage or end-to-end TUN recovery.
